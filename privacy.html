Privacy Policy

Last updated: 19 November 2026

Leonido Shorts ("the tool") is a self-hosted application used only by the owner of the GTA6 Leonido YouTube channel to upload videos to that channel. This policy explains what data the tool accesses and how it is handled.

Use of YouTube API Services

The tool uses YouTube API Services. By using the tool, the user agrees to be bound by the YouTube Terms of Service. YouTube data is also subject to the Google Privacy Policy.

Data we access

  • Google / YouTube account authorization: the tool asks the channel owner to sign in with Google (OAuth 2.0) and requests only these scopes: youtube.upload (to upload videos) and youtube.readonly (to read the name of the owner's own channel to confirm the right channel is connected).
  • YouTube video IDs: after an upload, the ID of the newly created video is saved so the owner can see which clips are already published.
  • The tool does not read, collect or store data about other YouTube users, viewers, comments, subscribers or analytics.

How data is used

Authorization data is used solely to upload the videos the channel owner has approved to the owner's own channel. It is never used for advertising, profiling, or any other purpose.

Storage and sharing

  • The OAuth token and the list of uploaded video IDs are stored only on the channel owner's own computer, in local files. There is no server, cloud database or third-party analytics.
  • No data is sold, shared with, or disclosed to any third party.
  • The tool does not use cookies or similar tracking technologies; it does not run on a public website and does not track anyone.

Retention and deletion

  • Data is kept only as long as needed to run the tool. The owner can delete all stored data at any time by deleting the local token.json file and the data/ folder.
  • Access can be revoked at any time on the Google security settings page: https://security.google.com/settings/security/permissions. After revocation the tool can no longer access the account.
  • YouTube API data that is no longer needed, or whose authorization is revoked, is deleted from local storage within 30 days.

Changes

If this policy changes, the updated version will be published on this page with a new "Last updated" date.

Contact

Questions about this policy can be sent via the project's GitHub issues page.
